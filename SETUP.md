# Como publicar este perfil no GitHub

O GitHub mostra um README especial no topo do perfil quando existe um repositório público com exatamente o mesmo nome do usuário.

Para o seu caso:

1. Crie um repositório público chamado `pcsouzafv`.
2. Envie o arquivo `README.md` desta pasta para a raiz do repositório.
3. Envie também a pasta `.github/workflows/snake.yml` se quiser a animação de contribuições.
4. Abra a aba `Actions` do repositório `pcsouzafv/pcsouzafv`.
5. Rode manualmente o workflow `Generate contribution snake` uma vez.
6. Volte para `https://github.com/pcsouzafv` e confira o README no topo do perfil.
